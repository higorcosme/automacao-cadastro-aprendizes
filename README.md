# automacao-cadastro-aprendizes

Automação de Cadastro de Jovens Aprendizes

📌 Sobre o Projeto

Projeto desenvolvido utilizando Power Query, PowerShell e Microsoft Excel para automatizar o processamento e a consolidação de formulários de jovens aprendizes em uma base centralizada de dados.

A solução foi criada com o objetivo de reduzir atividades manuais, padronizar informações e simplificar a atualização de cadastros.

🚀 Funcionalidades

Consolidação automática de múltiplos formulários Excel.
Processo ETL utilizando Power Query.
Conversão automatizada de arquivos .xls para .xlsx.
Atualização simplificada da base de dados.
Estrutura preparada para automação de processos administrativos.

🛠 Tecnologias Utilizadas
Microsoft Excel
Power Query
PowerShell

💡 Objetivo

Resolver a necessidade de consolidar informações de múltiplos formulários de jovens aprendizes em uma base centralizada, automatizando etapas de tratamento, padronização e atualização dos dados para tornar o processo mais eficiente e escalável.

📈 Resultado
Centralização das informações de jovens aprendizes em uma única base de dados.
Eliminação da necessidade de consolidação manual dos formulários.
Automatização do tratamento e atualização das informações.
Estrutura preparada para inclusão de novos registros com atualização simplificada.
